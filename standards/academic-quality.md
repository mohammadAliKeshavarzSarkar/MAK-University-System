# Academic quality standard

**Status:** Required baseline for university workflows. Specific course requirements may add stronger constraints.

## 1. Start from the real assignment

- Identify the learning objective, audience, topic scope, instructor instructions, rubric, timing/length, submission format, and available materials.
- Prefer an accurate, feasible scope over impressive but unsupported breadth.
- State assumptions when required information is missing; do not quietly invent it.

## 2. Technical correctness and understanding

- Define terms and distinguish related concepts carefully.
- Explain the reasoning or mechanism, not only a list of terms.
- Check formulas, notation, pseudocode, units, variable definitions, architectural flows, and code behavior.
- Separate demonstration data from actual experimental results.
- Explain limitations, trade-offs, assumptions, and sources of uncertainty.

## 3. Communication

- Use a clear progression: question/problem → explanation → evidence/example → implication, adapting it to the task.
- Prefer concrete examples and diagrams that aid understanding.
- Avoid dense, decorative, or repetitive material.
- Use precise language without unnecessarily inflating claims.
- For mixed Persian/English work, verify right-to-left and left-to-right reading order, numbers, code, and typography.

## 4. Presentation and accessibility

- Make information readable at the expected viewing distance and medium.
- Use sufficient contrast, clear labels, meaningful titles, and a consistent visual hierarchy.
- Don't rely on color alone to encode a distinction.
- Prefer editable figures and charts where possible.
- Provide source credits, chart units, relevant legends, and image attribution.
- Test the exported format instead of assuming that the editor preview is sufficient.

## 5. Delivery checklist

- [ ] Satisfies the assignment and format requirements
- [ ] Core concepts and technical details checked
- [ ] Citations and source boundaries checked
- [ ] Examples and numbers clearly identified
- [ ] Grammar, typography, and directionality reviewed
- [ ] Figures, charts, and equations readable and correct
- [ ] No clipped/overflowing content or broken external assets
- [ ] Final exports open successfully and match expectations

Improve this standard only when real university work reveals a recurring gap.
