# Agent guidance — MAK University System

This file is the entry point for agents that **can read this repository**. It does not by itself change the instruction hierarchy of ChatGPT or other tools.

## Scope and reading order

For any university-related task using this repository:

1. Read [README.md](README.md) to establish the project scope.
2. Read [standards/academic-quality.md](standards/academic-quality.md).
3. Read [standards/source-integrity.md](standards/source-integrity.md).
4. Read only the workflow relevant to the task. For presentations use [skills/frame-presentations/SKILL.md](skills/frame-presentations/SKILL.md), then [design/frame-guidebook.md](design/frame-guidebook.md).
5. Apply explicit current task instructions, course rubrics and provided source materials. Do not assume repository defaults override them.

## Design learning workflows

If the goal is to **learn or test** grid composition, typography, hierarchy, slide rhythm, or motion, use [skills/design-learning/SKILL.md](skills/design-learning/SKILL.md) and the relevant topic module. Check its [seven-source catalog](skills/design-learning/SOURCES.md). Preserve the distinction between the original source context and FRAME's own experiments. These modules do not override confirmed brand standards and do not automatically authorize producing a full deck.
## Data visualization learning and production

For scientific charts, evaluation curves, exploratory plots, or web visualizations, load [skills/data-visualization/SKILL.md](skills/data-visualization/SKILL.md) and its [five-source catalog](skills/data-visualization/SOURCES.md) as needed. Verify dataset origin, calculations, scales, labels and source attribution **before** styling. Treat interactive HTML, a static SVG/PNG, and a native editable PowerPoint chart as different deliverables. Do not treat synthetic values as empirical results. For teaching, revisiting, or continuing the twelve FRAME DataViz studies, use the [Data Visualization Learning Lab](skills/data-visualization-learning/SKILL.md), its [learning path](skills/data-visualization-learning/LEARNING-PATH.md), and [source evidence register](skills/data-visualization-learning/EVIDENCE.md). The current completed sequence ends at Study 12; Study 13 is only a proposal.


## Behavior

- Clarify the purpose, intended audience, available sources, required deliverable and time/length constraints, using provided information before asking questions.
- Preserve the distinction between verified facts, source claims, interpretations, hypothetical examples, and missing information.
- Do not fabricate references, findings, statistics, datasets, achievements, credentials, or software behavior.
- Inspect existing work before overwriting or proposing duplicate structures.
- Challenge unclear assumptions and avoid excessive process.
- Keep outputs editable when the deliverable requires it; perform practical visual and factual QA.
- Do not treat a draft, reference mockup, visual sample, or portfolio résumé as factual academic evidence.
- Do not upload sensitive user data, private course material, copyrighted materials without permission, or secrets to this public repository.
- Do not change brand logos, typography, or color tokens silently. Mark unresolved choices as open and ask for explicit approval when a decision would be irreversible or materially consequential.

## Decision status vocabulary

- **Required:** expressly established by the user or approved brand identity.
- **Working default:** practical selection pending tests or confirmation.
- **Optional:** available choice, used only when useful.
- **Open:** not yet approved; keep clearly labeled.

## Working in Git

Prefer small, reviewable changes and clear commit messages. For structural or policy revisions, use a branch and pull request when supported. Do not merge or publish private assets without explicit authorization.

## Presentation-specific scope

FRAME produces technically accurate and visually clear academic presentations. It uses the shared MAK identity as its foundation, but does **not** copy every Canva design. Follow the FRAME skill and guidebook for production details.

This file is navigation, not a replacement for the task-specific documents.
