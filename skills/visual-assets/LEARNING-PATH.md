# FRAME / IMAGE — Twelve-lesson learning path

**Status:** Guided lessons 01–12 studied; production pilots 01–02 completed with documented limitations. This is a learning map, not twelve separate skills or evidence of measured educational effectiveness. Use [the facilitator and production workflow](SKILL.md), [source catalog](SOURCES.md), and [pilot QA](PRODUCTION-QA.md).

| Lesson | Learning objective and exercise | Review question / limitation |
| --- | --- | --- |
| 01 — Visual literacy | Compare decorative AI imagery, contextual hardware photography and a schematic neural network for one teaching objective; classify the image's function. | Which one actually explains information flow? Reference images were illustrative, not cleared assets or comprehension research. |
| 02 — Research and selection | Refine a generic query into a subject-specific and art-directed search; shortlist original source pages; draft an asset record. | Can the actual file, creator, license and intended use be verified? |
| 03 — Editorial photography | Compare architectural monochrome, technical macro, minimal editorial and documentary directions; specify lighting, perspective and materials. | What does the visual direction add? Different reference photos are not a controlled lighting experiment. |
| 04 — Composition and cropping | Compare full bleed, split, inset, image-dominant, vertical and asymmetric placements using schematic geometry; contrast Fit, Fill and Stretch. | What meaningful details disappear when the focal position or crop changes? |
| 05 — Color treatment | Change saturation, contrast, brightness and warmth of one schematic asset; distinguish natural, monochrome, neutral and brand-directed treatments. | Is color part of the evidence? The interactive controls were illustrative, not a calibrated image pipeline. |
| 06 — AI generation | Compare subject-only, art-directed and slide-specific prompt briefs; specify purpose, subject, medium, composition, lighting, palette, constraints and output. | Does the actual generation satisfy the brief? Reference pictures were not outputs of a controlled prompt experiment. |
| 07 — Editing and refinement | Simulate localized object, background, accent and lighting changes; record preserve/change/exclude instructions. | How will exact preservation be tested? Pilot 02 later demonstrated nonidentical surrounding pixels. |
| 08 — Technical illustration | Construct a simplified RAG pipeline; compare architecture, process, exploded and sequence representations; keep diagram source. | Do connectors, abstractions, omissions and labels agree with the actual system? |
| 09 — Conceptual metaphors | Explore abstraction, scalability, optimization, attention, complexity and uncertainty; compare metaphor, explanatory schematic and mathematical plot. | Which properties map to the concept, and where does the analogy fail? |
| 10 — Image–typography integration | Vary image allocation, headline size and placement; compare type-dominant, balanced, image-dominant and immersive compositions. | Does text remain legible without obscuring evidence? WCAG contrast is a useful screening reference, not a projector certification. |
| 11 — Formats and production | Estimate pixel coverage after Fit/Fill, compare vector/raster and transparency, and plan embedded high-quality masters. | Is the actual file format valid, and does the final viewer render it? |
| 12 — Rights, provenance and QA | Review Creative Commons terms and TASL attribution; draft a manifest, text alternatives and a complete production checklist. | Is the specific intended distribution permitted, and is each claim about QA supported? |

## Applied practice

The original lessons used references, schematic diagrams and interactive demonstrations. Do not claim they were twelve rendered presentation experiments. The two subsequent pilots tested a subset of the workflow using actual files. Their source archives, precise results and remaining gaps are recorded in [production QA](PRODUCTION-QA.md).

When revisiting a lesson, choose a concrete slide objective; reopen the relevant source; hold one variable fixed where possible; inspect the actual candidate; explain a limitation; and record only observed results. For generated content, critique the real output rather than infer behavior from a prompt. Avoid automatically producing a full deck for every lesson.

**Next:** Apply the skill to an authentic presentation. Prioritize external photo retrieval/embedding, independent multi-scene consistency, and target-computer checks according to the actual task.
