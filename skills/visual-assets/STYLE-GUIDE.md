# FRAME / IMAGE — Art direction and composition

**Status:** Working defaults and proposed directions; [the FRAME guidebook](../../design/frame-guidebook.md) remains authoritative for confirmed brand identity.

## Visual role first

A visual should support the slide's communication objective. Avoid default robot heads, glowing networks and unrelated stock photography when the actual mechanism can be shown clearly. Not every slide needs a picture. Use conceptual images for intuition and atmosphere, then use accurate diagrams, calculations or data for formal explanation.

## Candidate visual directions

| Direction | Best use | Restraint |
| --- | --- | --- |
| Architectural monochrome | Structure, systems, geometry | Do not mistake a physical metaphor for a real architecture. |
| Technical macro | Hardware and materials | Authentic detail for factual claims; generated macro-style art is illustrative. |
| Minimal editorial | Openings and conceptual context | Controlled focus, negative space and material texture. |
| Scientific documentary | Real equipment, people, environments | Authenticity and rights before grading. |
| Conceptual 3D / graphic abstraction | Abstract computer-science concepts | Use one primary metaphor and state its boundary. |
| Technical linework | Mechanisms and relations | Correct structure and readable labels before styling. |

These are choices, not mandatory templates. Use established Paper #F5F3EE, Ink #161616, restrained Signal #E64B3C, and confirmed Inter for Latin-script slide text. Original logo assets remain unchanged; no new colors or Persian typeface are approved here. Warm neutral tones are optional art-direction choices, not new brand tokens. Do not recolor meaningful scientific or interface information to match brand colors.

## Brief template

- Slide message and image function.
- Exact subject, medium and source requirements.
- Image container dimensions/aspect ratio, focal position, text space, crop requirements.
- Lighting, viewpoint, materials, background and tone.
- Meaningful features to preserve, prohibited inventions, intended distribution.
- Editable elements, caption/credit and alternate explanation.

## Compose with typography

Use full bleed for an intentional immersive composition, split or editorial inset for text/visual balance, and image-dominant layouts for observation. Fit preserves the entire image; Fill crops without stretching. Select focal position intentionally. Keep headlines, captions, labels and equations native and readable. Use overlays only where they improve contrast without obscuring important details. WCAG's normal-text 4.5:1 and qualifying-large-text 3:1 are useful screening values for solid colors; inspect local photographic contrast and real projection separately. Adapt reading order for RTL without automatically mirroring meaningful diagrams/photos.

## Preserve visual semantics

Correct source flaws only as permitted. For evidential material, retain originals, apply only justified and documented changes under applicable scientific rules, and never fabricate or remove evidence. Do not assume creative treatments are permitted by the license. For metaphors, document the target, familiar source, intended mapping and limitations: a modular grid suggests additional resources but not linear scaling; selective illumination suggests weighting, not binary neural attention; valleys suggest minimization, not guaranteed global convergence.

## Consistency without repetition

Coordinate viewpoint, materials, lighting, framing and contrast across related assets. Create a small reference set if the task needs a series. Preserve visual variety and compare actual candidates. Pilot 02 demonstrates a related generated image pair and an authored vector illustration, not a successfully generated independent multi-scene image series.
