# Learn — Visual Rhythm across Slides

**Status:** Original FRAME learning practice; not a specific rule from Müller-Brockmann.

## Source boundaries

[Poster House — The Swiss Grid](https://swissgrid.posterhouse.org/) and [Niggli's Grid Systems description](https://niggli.ch/en/products/rastersysteme-fur-die-visuelle-gestaltung) help us reason about coherent visual structure. **Neither source has been verified as prescribing a seven-slide PowerPoint rhythm, slide-density scale or pacing formula.** This module is derived from our Grid Study 03 experiment.

## Learning objective

Maintain consistent identity while making intentional variations in density, illustration, math, whitespace and pause. Clarify the distinction between **visual density** and **cognitive difficulty**: a slide with a single complex equation may be visually sparse and conceptually demanding.

## Rhythm-map exercise

1. Establish the teaching narrative and the learner's prior knowledge.
2. Label every slide by its *role* (question, contrast, definition, mechanism, formula, worked example, evidence, pause, synthesis, sources) and qualitative visual density.
3. Locate long runs of similar layouts or demanding explanations. Do not assume these are wrong; match them to the topic and audience.
4. Sketch an alternative sequence with deliberate changes of scale, whitespace and focal element. Keep the same factual scope unless it is clearly marked as an abridged study.
5. Preserve the shared MAK visual vocabulary: Paper, Ink, restrained Signal, Inter for Latin text, approved logo artwork, consistent alignment and truthful diagrams.
6. Review consecutive slides at slideshow speed **and** full-slide size, not only in a contact sheet.
7. Document where a pause helps, where it interrupts, and where a dense slide is unavoidable.

## Reference FRAME exercise

Grid Study 03 selected a **seven-slide abridged** Self-Attention arc: question → context contrast → Q/K/V → attention formula → synthetic calculation → illustrative matrix → synthesis. It omitted some topics from the original 11-slide pilot intentionally; it is **not** a substitute for the original technical scope. The dark formula slide was a design hypothesis, not a universal recommendation.

## Deliverable

Produce a slide-role map and a concise critique or two sequences for comparison. Do not impose fixed alternation, mandatory dark slides, or a seven-slide length. For moving elements or transitions, use [motion choreography](../design-motion/SKILL.md). For fully sourced final decks, use [FRAME production](../frame-presentations/SKILL.md).
