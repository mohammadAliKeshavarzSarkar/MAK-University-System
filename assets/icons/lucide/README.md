# Curated Lucide SVGs for MAK University System

These six **unmodified SVG files** are sourced from the [official Lucide GitHub library](https://github.com/lucide-icons/lucide) and support our Lucide-first presentation iconography. **This is not the full Lucide package.**

Follow the [iconography standard](../../../design/iconography.md). Domain-specific, original custom icons and technical diagrams are explicitly allowed when more accurate.
